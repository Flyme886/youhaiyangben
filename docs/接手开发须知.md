# 接手开发须知

写给接手这个项目的同学。看完这份就能判断「哪块是什么、缺什么、从哪开始改」。

---

## 一、这是什么

「舆见」微信小程序（注册名：样本任务台）—— 内容审核场景的有害样本自动化任务台。

业务闭环只有四步：

1. 业务用户在手机上上传一个 Excel（表头含原始链接列）；
2. 云服务器逐条打开链接、**截整页图**；
3. 每 50 条拼一份 Word，每条样本三段：编号标题 / 原始链接 / 页面截图；
4. 用户在小程序里下载或转发 Word。

管理员功能（登录态维护、批量重跑、日志排查）留在网页后台，不在小程序里。
飞书机器人那条路线已于 2026-10-30 废弃，代码还在但不用管。

## 二、仓库结构

```text
youhaiyangben/
├── app/                       FastAPI 后端（Web 后台 + 小程序接口）
│   ├── main.py                入口：页面路由 + /internal/* + 挂载 /api/wx/*
│   ├── api_wx.py              小程序 REST 接口（12 个）
│   ├── wechat_auth.py         code2session 换 openid + 自签 token
│   ├── db_wx.py               任务归属字段迁移 + 分页查询
│   ├── db.py / config.py / task_runner.py
│   └── templates/ static/     网页后台
├── miniprogram/               微信原生小程序（零构建、无 npm 依赖）
│   └── config/index.js        ← 小程序端唯一需要动的地方（后端地址）
├── skills/harmful_sample/     抓取与成 Word 的脚本
├── deploy/                    nginx 配置、systemd、部署脚本
├── docs/                      设计文档（本文件、接口层说明、抓取改造方案）
└── tests/test_api_wx.py       接口集成自检，82 项断言
```

线上部署路径固定是 `/opt/harmful-sample-web`。

## 三、跑起来（从零到能点开小程序）

### 1. 后端

```bash
git clone https://github.com/Flyme886/youhaiyangben
cd youhaiyangben
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env
```

然后编辑 `.env`，**这四项必须先配**：

| 变量 | 值 |
| --- | --- |
| `APP_PASSWORD` | 网页后台密码 |
| `WX_APP_ID` | `wx163f957c85ceff4b`（在 `miniprogram/project.config.json` 里也有） |
| `WX_APP_SECRET` | 微信公众平台 → 开发管理 → 开发设置 里取，**只放 .env** |
| `WX_TOKEN_SECRET` | `python3 -c "import secrets; print(secrets.token_urlsafe(32))"` |

`.env` 里其余项的含义见 `.env.example` 的逐行注释，都有默认值，不动也能跑。

```bash
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8787
curl -s localhost:8787/api/wx/health          # 期望 {"status":"ok",...}
```

⚠️ 依赖必须按 `requirements.txt` 钉的版本装。用 `pip install fastapi` 装最新版会踩到
starlette 删掉旧 `TemplateResponse(name, context)` 签名的问题，网页后台 `/login` 直接 500。

### 2. 小程序端

1. 微信开发者工具 → 导入项目 → 选 `miniprogram/` 目录；
2. AppID 用 `wx163f957c85ceff4b`（需要**你自己的微信号被加为该小程序的开发者**，
   让项目 owner 在微信公众平台「成员管理」里加你，否则无法真机预览）；
3. `miniprogram/config/index.js` 里 `PROFILES.dev.baseUrl` 默认指向线上
   `https://zhuiguang.click`。如果你要连本机后端，改成 `http://127.0.0.1:8787`；
4. 「详情 → 本地设置」勾选 **不校验合法域名、web-view、TLS 版本以及 HTTPS 证书**。

`project.private.config.json` 是开发者工具自动生成的本地文件，已在 `.gitignore` 里，
**不是缺失项**，你打开工具后它会自己出现。

## 四、请求链路

```text
小程序 → https://zhuiguang.click/api/wx/* → nginx(443) → 127.0.0.1:8787 FastAPI
```

- FastAPI 只监听回环地址，永不直接对公网暴露；
- nginx 上 `location /api/wx/` 是最长前缀，压过既有的 `/api/`；
- 生产环境 `zhuiguang.click` 已完成 ICP 备案（2026-10），但仍需在微信公众平台
  「开发设置 → 服务器域名」把同一个域名**同时**填进
  `request` / `uploadFile` / `downloadFile` 三类白名单 —— 三类缺一类，
  上传或下载就整条挂掉。

## 五、硬约束（改之前先看，别破）

1. **交付物必须是页面截图。** 不接受用接口 JSON 或媒体文件替代截图的方案，
   接口只能用于打开页面、维持登录态。
2. **抓取与生成链路必须完全跑在云服务器上。** 不允许依赖任何人的本地电脑
   （包括浏览器自动化的人工介入方案）。
3. **AppSecret 绝不能进 `miniprogram/`。** 小程序里任何位置出现 AppSecret 视为安全事故。
4. **`TASK_ROOT` / `SKILL_DIR` 必须绝对路径。** worker 的工作目录是 `task_dir`，
   相对路径会被解析到 `data/tasks/<id>/` 下，任务一提交就报找不到 `excel_to_word.py`。
5. **`.env` 不入库。** 仓库是公开的。

## 六、排障对照表

| 现象 | 大概率原因 | 查哪里 |
| --- | --- | --- |
| 所有请求 404 | `app/main.py` 的 `include_router(wx_router)` 没生效，或 nginx 没配 `/api/wx/` | `curl localhost:8787/api/wx/health` |
| 401 Invalid bot API key | 调的是 `/internal/*`，`BOT_API_KEY` 留空即全拒 | `.env` 的 `BOT_API_KEY` |
| 登录一直转圈 / 失败 | `WX_APP_ID` / `WX_APP_SECRET` 没配或配错 | 后端日志里的 code2session 返回码 |
| `url not in domain list` | 微信域名白名单没配好 | 公众平台服务器域名，或开调试模式 |
| 网页后台 `/login` 500 | starlette 版本不对 | 按 `requirements.txt` 重装 |
| 任务提交后立刻失败 | 路径写成了相对路径 | `.env` 的 `TASK_ROOT` / `SKILL_DIR` |
| 大量 `login_required` | `storage_state.json` 过期（默认 7 天） | 刷新登录态，见 `STORAGE_STATE_MAX_AGE_DAYS` |
| 大量 `captcha` | 风控。看 `CAPTCHA_PAUSE_THRESHOLD` 与代理 | `.env` 的 `CAPTURE_*` |

跑一次全量自检：

```bash
.venv/bin/pip install httpx
.venv/bin/python tests/test_api_wx.py
```

## 七、当前状态与下一步

**已完成**：小程序端 5 个页面 + 后端 12 个接口 + 归属隔离 + nginx 配置 + 82 项接口断言。
小程序 ICP 备案已通过，当前处于测试阶段。

**已知问题（这是接手后最该先看的地方）**：

- **抓取成功率是最大瓶颈。** 历史实测 200 条 URL 只有 1.5% 成功，
  其中 64% `blocked_or_blank`、28.5% `login_required`、5.5% `captcha`。
  接口与页面都通了，但业务价值的瓶颈在这里。
  最新方案：`docs/截图获取调研与方案.md`（v2.0，取代 `docs/抓取改造方案.md` 的第四、五节）。
- `.env.recommended` 里用了行内注释（`KEY=值  # 说明`），而 `app/config.py`
  的 `_load_dotenv()` 不剥离行内注释 —— 值会带上注释文本。
  **别直接 cp 那个文件当 `.env`**，照 `.env.example` 来。
- **只能从聊天记录选文件。** 用的是 `wx.chooseMessageFile`，选不到手机本地文件管理器里的文件，
  所以界面引导用户「先把 Excel 发到任意聊天（推荐文件传输助手）」。这是微信 API 限制，不是 bug。
- `wx.chooseMessageFile` 在部分安卓机型上返回的临时路径可能失效：新建页提交前会用
  `getFileInfo()` 校验一次，失效时提示重新选择；同时前端拦下超过 10 MB 的文件（后端暂无上限）。

**下一步建议顺序**：先跑通 `tests/test_api_wx.py` 确认接口层无回归 →
再看 `docs/抓取改造方案.md` 提升成功率 → 最后补管理端（登录态维护、批量重跑）。
