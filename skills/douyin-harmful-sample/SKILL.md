# 有害样本 Word

一份监测 Excel 进，一份（或几份）Word 出。每条样本只有三段：`N.标题` / 原始链接 / 页面截图。

没有第二个产物。

## 交付契约

1. **只交 docx。** 不附处理日志、截图清单、交付说明、压缩包，也不交付脚本。
2. **缺图在对话里说。** 报编号、平台、作者、一句原因。不写进文档，不落成文件。
3. **文档里除了三段版式，一个字符都不多写。** 缺图位置留白。

判断标准只有一条：用户拿到 docx 能不能直接上报。

## 一条命令

```bash
MP=~/.workbuddy/skills/douyin-harmful-sample/scripts/mp
zsh $MP/run.sh <xlsx> <outdir> [--prefix 名字] [--batch 50] [--space 空间名] [--no-probe]
```

固定五步：

1. **清单** — 表头自适应，出 manifest.json。无标题用摘要兜底。
2. **探测** — 每个平台只抓 1 条，半分钟拿到可达性表。先知道哪个平台打不开，再决定铺不铺开。
3. **全量** — 单线程分片抓。
4. **出 Word** — 按 ≤50 条切份，编号跨文件连续。
5. **结构自检**。

探测不是可选项。小红书的 token 缺失、B站的登录浮层、贴吧的删帖页，都会在探测这一步现形，而不是跑完几十页才发现。

## 版式（硬约束）

| 段 | 内容 | 样式 |
|---|---|---|
| 1 | `N.标题` | 微软雅黑 12pt 加粗 `1F4E79`，段前 2pt |
| 2 | 原始链接 | 9.5pt `0B60B0`，段前 4pt |
| 3 | 页面截图 | 居中，横图固定宽 16.0cm，竖图按高 20.5cm 限幅 |

- 页面 Letter 21.59×27.94cm，左右边距 3.175cm，上下 2.54cm
- 标题内换行折叠成空格，超 32 字截断加「…」
- 编号跨文件连续（1..N），每份 ≤50 条
- 链接照抄原表，不改写
- 禁止出现：批次大标题、编号范围行、元信息行、摘要段、原文全文、判定框、页眉页脚、任何说明文字

## 输入表

按表头识别字段，不要按列序号硬编码。见过两种：

| 表头 | 标题 | 链接 | 平台 | 作者 | 摘要 |
|---|---|---|---|---|---|
| `标题/微博内容`、`原文/评论链接`、`原文作者`、`来源网站` | 标题/微博内容 | 原文/评论链接 | 来源网站 | 原文作者 | 摘要 |
| `原链接` + 两个 `标题` | 第二个「标题」 | 原链接 | 第一个「标题」 | 发布人 | 摘要 |

标题为空、「无」、「（无标题）」时，用摘要前 32 字兜底，摘要也空才写「（无标题）」。摘要是平台侧的图文识别文本，常有错字和断句，原样使用。

## 抓取

浏览器只用 ego lite。真实浏览器 + 持久 profile，风控表现远好于无头方案，登录态可复用。

**铁律**

- 单线程。并发立刻换来验证码成簇，还连累整个 IP 限流。
- `waitUntil:"domcontentloaded"`。抖音、B站、小红书的流式页面永远等不到 load。
- 每 10–12 条重建标签页。渲染进程跑十几条后从 2 秒劣化到几分钟。
- 撞到验证码冷却 60–90 秒重新导航，还不行留白。不破解验证码，这是授权边界。
- 按归一化地址去重：同一条微博被 4 个号转发，截一次图复用 4 次。

**各平台取图地址**（文档里的链接始终是原表原文，只有导航地址变）

| 平台 | 导航地址 | 要点 |
|---|---|---|
| 抖音 | `douyin.com/video/{id}` | `/share/video/` 会跳验证码中间页 |
| 微博 | `m.weibo.cn/detail/{bid}` | 桌面版必撞登录墙，移动版匿名可读正文与评论 |
| 小红书 | `explore/{id}?xsec_token=…` | 必须带 token，见下 |
| B站 | `t.bilibili.com/{id}` 或 `bilibili.com/video/BV…` | 动态页有登录浮层，不挡正文 |
| 贴吧、微信、头条、搜狐、酷安 | 原地址 | 基本直开 |

**小红书必须带 token。** 监测表导出的 `discovery/item/{id}` 不含 `xsec_token`，直开一律 404，换 `explore/` 也一样。补法：登录态下站内搜索 `search_result?keyword=…`，结果卡片的 `<a href>` 里带真实 token，回收后拼成 `explore/{id}?xsec_token=…`。关键词按「事件实体 + 书名 / ISBN / 机构」组合多轮搜。搜不到、进作者主页也加载不出的，判为已删或私密，留白。

## 状态判定

不要用正文字数判断抓没抓到。按顺序认错误页特征：

| 状态 | 判据 | 归入 |
|---|---|---|
| `ok` | 正常正文 | 附图 |
| `deleted` | 页面明说「不存在 / 已删除 / 页面不见了 / 内容已失效」 | **附图，这是有效证据** |
| `captcha` | 安全验证 / 人机验证 / 访问过于频繁 | 留白 |
| `login_wall` | 只给登录框，正文看不到 | 留白 |
| `blocked_or_blank` | 正文不足 20 字，且不属上三类 | 留白 |

三个真实反例：小红书的「安全验证」页曾被当成成功存了一张验证码图；贴吧「帖子可能已被删除」和微博「该微博不存在」曾被判成失败差点丢掉。前者是假证据，后两者是真证据。

## 做完

1. 跑结构自检：每份 ≤50 条、编号连续、标题段后紧跟 http 链接段、无禁用文案、图片宽高不超限。
2. 抽看一两张截图。标题对不等于图对。
3. 对话里回一句，报完就结束：

```
交了 3 份 docx，150 条，146 张图。
4 条没取到：2 条小红书缺 token、1 条头条超时、1 条贴吧已删（已保留截图）
```

## 不要做

- 不要 clone 私有仓库、不要用 `excel_to_word` 那套旧链（仓库 `skills/harmful_sample/`、本地 `scripts/legacy/` 都是遗留，不要碰）。
- 不要产出处理日志、截图状态表、交付说明、压缩包。
- 不要在文档里写「截图待补」「需人工核验」「部分完成」。
- 不要用站内搜索页、他人转发页冒充原帖。
- 不要把没从 Excel 或页面里读到的内容写进文档。

## 工具

`scripts/mp/`：

| 文件 | 作用 |
|---|---|
| `run.sh` | 端到端入口，五步串起来 |
| `make_manifest_generic.py` | xlsx → manifest.json，表头自适应 |
| `mkconfig.py` | 生成抓取配置，`--probe` 出每平台一条的探测清单 |
| `capture_multi.js` | ego lite 多平台截图，状态机在上面 |
| `run_capture_multi.sh` | 分片调度 + 限流冷却 + 断点续跑 |
| `summary.py` | 按平台统计有图 / 已删 / 缺图，列缺图条目 |
| `build_docx.py` | 出 Word |
| `verify_docx.py` | 结构自检 |

`capture_multi.js` 读 `globalThis.__CAPTURE_ENV`（由 `run_capture_multi.sh` 注入）。单独跑时配置项：`manifest` / `shots_dir` / `results_dir` / `space` / `recycle` / `max_attempts` / `platform_settle`。
